V3 — React Native (appli mobile) + web

Objectif : réutiliser le maximum.

tu réutilises :

domain/ (100%)
lib/ (quasi 100%)
data/ (interfaces + parfois impl partielle)

tu remplaces :

components/ (web → RN)
styles/ (SCSS → StyleSheet/tailwind RN/etc.)
app/ (Next routing → RN navigation)

Stratégie :

garde le métier hors UI = tu peux refaire l’UI sans réécrire les règles.

✅ C’est la meilleure façon de préparer V3 sans sur-architecturer.
