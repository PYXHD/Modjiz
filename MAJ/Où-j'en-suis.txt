1. Architecture styles

styles/

tokens/ → couleurs (light/dark)
base/ → reset + styles globaux
tools/ → mixins (typo, spacing)
globals.scss → point d’entrée

Séparation claire : tokens / base / tools / components.

/////////////////////////////////
2. Reset / Base

Reset minimal (box-sizing, margins, media, inputs)

base.scss :
background via --color-bg
texte via --color-text
font par défaut = --font-app
line-height global = 1.5
color-scheme: light dark

/////////////////////////////////
3. Système de couleurs

Tokens CSS dans :root

Overrides via [data-theme="dark"]
Couleurs stables pour émotions
Variables --color-on-dark / --color-on-light

Pas de duplication inutile

/////////////////////////////////
4. Fonts (Next.js moderne)

Fonts chargées avec next/font/local
Config dans styles/fonts.ts

Variables CSS :

--font-landing (Manrope)
--font-app (Sour Gummy)

Branchées sur <html> dans layout racine

Pas de @font-face manuel

/////////////////////////////////
5. Typographie (Sass system)

Map pour tailles :

xs / sm / md / lg / xl / xxl

Map pour poids :

light / medium / bold

Mixins :

font-landing
font-app
text(size, line-height)

Plus de valeurs “magiques” dans les composants

6. Spacing system

Échelle basée sur : 10 / 20 / 40 / 60 / 80 / 120

En px (choix assumé)
Map $spaces
Mixin générique space(property, size)
Interpolation Sass #{}
